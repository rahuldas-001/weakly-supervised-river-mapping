# weakly-supervised-river-mapping
Four-class braided river segmentation from Sentinel-1/2 with weak labels: Attention U-Net and SegFormer, spatial cross-validation, transfer to an unseen reach, and planform change analysis (Brahmaputra, 2019–2026).
